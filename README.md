Redis Integration Project

Overview

This project demonstrates how to use Python with Redis to perform basic CRUD (Create, Read, Update, and Delete) operations using data imported from the GitHub Archive dataset. 
Repository information is imported from a JSON file and stored in Redis hashes, allowing users to manage and analyze repository data through a command-line interface.

Features 

    1. Import GitHub repository data from a JSON file into Redis
    2. Create new repository records
    3. Read existing repository records
    4. Update repository watch counts
    5. Delete repository records
    6. Display the Top 10 Most Watched Repositories
    7. Count the total number of unique repositories stored in Redis

Technologies Used
  
    * Python 3
    * Redis
    * Git
    * GitHub
